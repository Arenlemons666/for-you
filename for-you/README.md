# 💕

An interactive pixel art love story, made with care.

## File Structure

Place **all files in the same folder** (root of the repo):

```
/
├── index.html
├── greeting_1.png
├── question_2.png
├── question_3.png
├── button_4.png
├── button_5.png
├── yes_6.png
├── no_7.png
├── ifyes_8.png
├── love_9.png
├── love_10.png
└── ONLY_-_LEEHI.mp3
```

## Deploy with GitHub Pages

1. Push everything to a GitHub repository
2. Go to **Settings → Pages**
3. Under *Branch*, select `main` and folder `/root`
4. Save — your page will be live at `https://yourusername.github.io/your-repo-name/`

## Story Flow

```
greeting → question → question → [press the button] → yes/no
                                                         │
                                               yes ──→ yes → if yes → love → love 💕
                                               no  ──→ no  → (loops back 🔁)
```

Music plays automatically on first tap/click.
